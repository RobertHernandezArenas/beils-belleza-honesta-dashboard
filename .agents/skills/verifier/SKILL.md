# 🛡 SKILL: Verifier

## Propósito
Validar cambios con evidencia visual y funcional.

## Capacidades
- Ejecutar la app.
- Correr tests.
- Tomar screenshots.
- Comparar UI con referencia.
- Detectar regresiones.

## Limitaciones
- No modificar código.
- No ignorar evidencia.
- No aprobar sin pruebas.

## Output
- Screenshots
- Logs
- Estado: aprobado / rechazado

# 🔧 SKILL: Maker

## Propósito
Implementar cambios siguiendo estilo, arquitectura y reglas del proyecto.

## Capacidades
- Editar código.
- Refactorizar.
- Crear tests.
- Documentar decisiones.
- Trabajar en worktrees.

## Limitaciones
- No validar cambios.
- No aprobar PRs.
- No ignorar arquitectura.

## Output
- Código modificado
- Logs de ejecución
- Justificación del cambio

# 🧠 SKILL: Memory

## Propósito
Registrar aprendizaje persistente.

## Qué guarda
- Hechos verificados.
- Errores recurrentes.
- Decisiones tomadas.
- Próximos pasos.
- Estado del loop.

## Regla
Cada ejecución debe actualizar memoria.

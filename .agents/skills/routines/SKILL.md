# 🔁 SKILL: Routines

## Propósito
Automatizar tareas largas y repetitivas.

## Ejemplos
- CI falló → triage
- PR abierta → review
- Deploy → QA visual
- 7:00 AM → digest

## Regla
Las routines se ejecutan sin intervención humana.

# 🧠 AGENT FOUNDATION — SkillForge.ai

Base unificada para agentes inteligentes: contexto, acción, verificación, memoria, evaluación y loops.

## Componentes
- Grill‑Me: preguntas críticas antes de actuar.
- Maker: ejecución de cambios.
- Verifier: validación visual y funcional.
- Memory: aprendizaje persistente.
- Routines: automatización de tareas largas.
- Loop Mode: ejecución iterativa profesional.

## Principios
- Evidencia antes de aprobación.
- Separación Maker/Verifier.
- Memoria como ventaja acumulativa.
- Automatización de tareas repetidas.
- Evaluación continua.
- Modelos asignados por tarea.

## Estructura del ciclo
Grill‑Me → Maker → Verifier → Memoria → Evaluaciones → Loop
